# how-organic-is-x402
*Analyzing organic vs. gamed transaction volume on the x402 agentic payments protocol*

x402 is an open-source payments protocol that lets AI agents pay for API calls with crypto micropayments. It's seen $108M in volume since launch in May 2025, though the quality of the data has been an area of debate. Artemis Analytics provides a comprehensive dataset distinguishing organic vs gamed x402 volume. The purpose of this analysis is to dive deeper into the data to answer a simple question: just how organic is x402?
